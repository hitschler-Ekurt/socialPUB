  <action>
    1. Create `src/app/api/admin/invite/route.ts`:
    - POST handler following the pattern from RESEARCH.md exactly
    - Step 1: Create server Supabase client, verify caller is authenticated via getUser()
    - Step 2: Query profiles table to verify caller has role 'admin' -- return 403 if not
    - Step 3: Parse request body with zod: { email: z.string().email(), full_name: z.string().min(1), role: z.enum(['admin', 'editor', 'viewer']) }
    - Step 4: Call createAdminClient().auth.admin.inviteUserByEmail(email, { data: { full_name, role }, redirectTo: `${process.env.NEXT_PUBLIC_APP_URL}/auth/confirm` })
    - Return 200 with user data on success, 400 with error message on failure
    - IMPORTANT: The inviteUserByEmail stores full_name and role in user_metadata, which the handle_new_user trigger picks up to create the profile row

    2. Create `src/app/api/admin/users/route.ts`:
    - GET handler: Return all profiles (for team list). Verify caller is admin.
    - PATCH handler for role updates and deactivation:
      - Parse body: { user_id: string, role?: 'admin'|'editor'|'viewer', is_active?: boolean }
      - Verify caller is admin
      - **Last-admin safeguard**: If changing role away from 'admin' OR deactivating an admin:
        - Count remaining active admins: SELECT count(*) FROM profiles WHERE role = 'admin' AND is_active = true AND id != target_user_id
        - If count === 0, return 400 with error "Letzter Admin kann nicht herabgestuft werden"
      - For role change: UPDATE profiles SET role = new_role WHERE id = user_id
      - For deactivation: UPDATE profiles SET is_active = false WHERE id = user_id
      - Return updated profile
    - NOTE: The `is_active` column exists on the profiles table (created in Plan 01-01 migration 001_initial_schema.sql as `is_active BOOLEAN DEFAULT true NOT NULL`). Do NOT add any ALTER TABLE or fallback logic -- the column is guaranteed to exist.
    - IMPORTANT: Use the server client (not admin client) for reading profile to respect RLS, use admin client only for auth admin operations if needed
