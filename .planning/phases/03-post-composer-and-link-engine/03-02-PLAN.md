   - Platform tabs show a separate Textarea bound to `captionOverrides[platform]` via `setCaptionOverride`.
   - If override is empty, show the main caption as placeholder with muted text "Haupttext wird verwendet".
   - Each platform tab shows its own character count with the platform-specific limit.
   - Include a "Zuruecksetzen" button to clear the override via `removeCaptionOverride(platform)`.

   - Use shadcn Button with variant "outline" for unselected, "default" for selected.
   - Show channel platform icon (Instagram/TikTok from lucide-react) next to name.

5. **Create src/components/composer/campaign-picker.tsx**:
   - Use `useCampaigns()` hook to fetch campaigns.
   - Render as shadcn Select component.
   - Each option shows campaign color dot + name.
   - Value bound to `campaignId` via `setCampaignId`.
   - Include "Keine Kampagne" option that sets campaignId to null.

   - Container component that lays out all sub-components.
