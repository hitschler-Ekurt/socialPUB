1. Create `src/lib/late-dev/client.ts` -- initialize Late.dev SDK with `process.env.LATE_API_KEY`. Export `lateClient` instance. Guard: throw if LATE_API_KEY missing in non-test env.

2. Create `src/lib/validations/channel.ts` -- Zod schemas: `connectChannelSchema` (platform: z.enum(["instagram", "tiktok"])), `callbackSchema` (code: string, state: string optional).

3. Create API routes:
   - `GET /api/channels` -- list all channels from Supabase ordered by created_at desc, return { data }
   - `POST /api/channels` -- internal use only, create channel record after OAuth callback
   - `PATCH /api/channels/[id]` -- update channel (e.g., name), admin-only role check via profile query
   - `DELETE /api/channels/[id]` -- soft-disconnect: set is_active=false, clear access_token/refresh_token. Admin-only.
   - `GET /api/channels/connect?platform=instagram` -- get Late.dev auth URL for the specified platform. Return { authUrl }. Use Late.dev SDK.
   - `POST /api/channels/callback` -- handle OAuth callback from Late.dev. Exchange code for account, store in channels table with platform, name, account_id, access_token, refresh_token, token_expires_at from Late.dev response. Return { data: channel }.
   - `GET /api/channels/health` -- call Late.dev health endpoint for all active channels. Return { data: [{channelId, status, expiresAt}] }. Map status to "connected"|"expiring"|"disconnected" based on token_expires_at (<7 days = expiring, past = disconnected).

   All mutation routes: verify auth via `supabase.auth.getUser()`, check admin role for connect/disconnect/delete. Use Zod validation. Return consistent { data } or { error } envelope.

4. Create `src/hooks/use-channels.ts`:
   - `useChannels()` -- TanStack useQuery with key ["channels"], fetches GET /api/channels
   - `useChannelHealth()` -- TanStack useQuery with key ["channels", "health"], fetches GET /api/channels/health, refetchInterval: 5 * 60 * 1000 (5 min)
   - `useConnectChannel()` -- TanStack useMutation, calls GET /api/channels/connect?platform=X, then window.location.href = authUrl
   - `useDisconnectChannel()` -- TanStack useMutation, calls DELETE /api/channels/[id], invalidates ["channels"]

5. Create components:
   - `channel-card.tsx` -- Card component showing: platform icon (Instagram/TikTok from lucide-react), account name (bold), avatar (or platform default), status badge (Badge component with green/yellow/red variants based on health status: "Verbunden" green, "Laeuft bald ab" yellow, "Getrennt" red), last synced date (relative via date-fns formatDistanceToNow). Accepts channel data + health status as props.
   - `channel-grid.tsx` -- Grid of ChannelCards (grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4). Handles loading (Skeleton cards) and empty state.
   - `connect-channel-dialog.tsx` -- Modal wizard: Step 1 shows two large buttons (Instagram, TikTok) with platform icons. On click, calls useConnectChannel mutation which redirects to Late.dev. Title: "Kanal verbinden". Subtitle: "Waehle eine Plattform aus". Admin-only via useRequireRole.
   - `channel-actions.tsx` -- DropdownMenu on each card with "Neu verbinden" (triggers connect flow for same platform) and "Trennen" (opens ConfirmDialog, then calls useDisconnectChannel). Admin-only actions.

6. Create `src/app/(auth)/channels/page.tsx` -- replaces no existing page (new route). Token expiration alerts: if any channel has "expiring" health, show Sonner toast warning on page load (once per session using sessionStorage flag).

7. Add sidebar nav item for channels -- the NAV_ITEMS update was done in Task 1, but verify the sidebar renders the new "Kanaele" item with Radio icon. If the sidebar uses dynamic icon lookup from lucide-react, ensure "Radio" icon is handled.
