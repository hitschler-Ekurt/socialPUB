1. Create `src/lib/validations/media.ts`:
   - `createMediaSchema`: file_name (string), file_path (string), file_size (number), mime_type (string), media_type (z.enum(["image", "video", "gif"])), width (number nullable optional), height (number nullable optional), duration_seconds (number nullable optional), thumbnail_path (string nullable optional)
   - `updateMediaTagsSchema`: tags (array of strings)
   - `mediaFilterSchema`: media_type (z.enum(["image", "video", "gif"]).optional()), tags (string optional -- comma-separated), search (string optional), page (number optional, default 1), limit (number optional, default 24)

2. Create `src/lib/utils/video-thumbnail.ts`:
   - Export `generateVideoThumbnail(file: File): Promise<Blob>` function
   - Creates video element with URL.createObjectURL(file), seeks to 25% of duration (min 1s)
   - Draws frame on canvas at 320px width, proportional height
   - Returns JPEG blob at 0.8 quality
   - Properly cleans up: URL.revokeObjectURL after capture
   - Error handling: reject with descriptive message if video load fails or canvas extraction fails
   - Follow the exact pattern from 02-RESEARCH.md

3. Create `POST /api/media/upload-url`:
   - Accepts { fileName, contentType } in body
   - Generates file path: `uploads/${crypto.randomUUID()}/${fileName}`
   - Calls supabase.storage.from("media").createSignedUploadUrl(filePath)
   - Returns { uploadUrl: data.signedUrl, filePath, token: data.token }
   - Auth required (any authenticated user can upload)

4. Create `GET /api/media`:
   - Accepts query params: media_type, tags (comma-separated), search, page (default 1), limit (default 24)
   - Query media table where is not deleted (no soft delete column exists, just filter active)
   - Filter by media_type if provided
   - Filter by tags using Supabase `.contains()` for array overlap if tags param provided
   - Filter by search using `.ilike('file_name', '%search%')` if search provided
   - Order by created_at desc
   - Paginate with .range() based on page and limit
   - Also return total count via separate count query for pagination UI
   - Return { data: media[], pagination: { page, limit, total } }

5. Create `POST /api/media`:
   - Validate with createMediaSchema
   - Get user, insert with uploaded_by = user.id, usage_count defaults to 0, tags defaults to []
   - Return { data: media } with 201

6. Create `PATCH /api/media/[id]`:
   - Validate with updateMediaTagsSchema
   - Update tags array on the media record
   - Return { data: media }

7. Create `DELETE /api/media/[id]`:
   - Delete the media record from database
   - Also delete the file from Supabase Storage: supabase.storage.from("media").remove([media.file_path])
   - If thumbnail_path exists, also remove: supabase.storage.from("media").remove([media.thumbnail_path])
   - Return { data: { id } }
   - Admin/editor only

8. Create `src/hooks/use-media.ts`:
   - `useMedia(filters: { media_type?, tags?, search?, page? })` -- useQuery key ["media", filters], fetches GET /api/media with query params. Returns { data, pagination, isLoading, error }.
   - `useUploadMedia()` -- useMutation. The mutation function accepts a File. Steps: (a) get signed URL from /api/media/upload-url, (b) PUT file to signed URL with Content-Type header, (c) if video, call generateVideoThumbnail, get thumbnail signed URL, upload thumbnail, (d) POST metadata to /api/media including thumbnail_path if video. On success invalidate ["media"]. Returns upload progress isn't natively supported with fetch, so just track pending state.
   - `useUpdateMediaTags()` -- useMutation, PATCH /api/media/[id] with tags. Invalidates ["media"]. Toast "Tags aktualisiert".
   - `useDeleteMedia()` -- useMutation, DELETE /api/media/[id]. Invalidates ["media"]. Toast "Datei geloescht".
   - `useBulkDeleteMedia()` -- useMutation, calls DELETE for each selected ID sequentially (or Promise.all). Invalidates ["media"]. Toast "X Dateien geloescht".
   - `useBulkTagMedia()` -- useMutation, calls PATCH for each selected ID with merged tags. Invalidates ["media"]. Toast "Tags hinzugefuegt".
  </action>
